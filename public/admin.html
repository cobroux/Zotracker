          Modifier la course

          Ravitaillements

          Ajoute-les ici ou clique sur le parcours dans la carte ci-dessous pour en placer un. Si ton fichier GPX contient des points (waypoints), ils sont importés automatiquement.

          Barrière d'arrivée

          Barrières au format H:MM depuis le départ (ex. 2:30). Facultatives, croissantes le long du parcours. Elles servent à la marge affichée aux supporters et à l'alerte privée.

          Parcours (fichier GPX)

          Exporte le tracé depuis le site de l'organisateur, Strava, Garmin Connect, Komoot, OpenRunner ou gpx.studio. Importer un nouveau parcours efface le suivi GPS de cette course.

            Voir la position

            Alertes réservées à toi et à tes contacts de confiance, jamais visibles par les supporters.

            1. Tes contacts de confiance

            1. Ils installent ntfy, une appli gratuite de notifications, sans compte (iPhone · Android).
            2. Ils touchent + et saisissent le code ci-dessous : c'est l'adresse privée sur laquelle tes alertes sont diffusées. Ils peuvent aussi ouvrir ce lien sur leur téléphone.

            Touche le code pour le copier. Tous les contacts abonnés reçoivent chaque alerte.

            2. Ton bouton SOS

            Ouvre ce lien sur ton téléphone et ajoute-le à l'écran d'accueil. En course, un appui de 2 s envoie ta position à tes contacts, sans mot de passe.

            Touche le lien pour le copier. Ne le partage à personne : il déclenche une vraie alerte.

              Fond de carte

              Le fond de carte est imposé par la configuration du serveur : il ne peut pas être changé ici.

              1. Crée un compte gratuit sur cloud.maptiler.com (sans carte bancaire).
              2. Va dans Account → API keys et copie ta clé.
              3. Clique sur la clé et ajoute ton domaine dans Allowed HTTP origins (et localhost pour tester) : personne d'autre ne pourra l'utiliser.

              Si le fond choisi ne répond pas, la carte bascule automatiquement sur un fond de secours.

              Double authentification

              En plus du mot de passe, un code à 6 chiffres affiché par une appli sur ton téléphone (Google Authenticator, Microsoft Authenticator, 1Password, Bitwarden…). Même si quelqu'un découvre ton mot de passe, il ne peut pas se connecter. Fortement recommandé.

              1. Ouvre ton appli d'authentification et scanne ce QR code (ou saisis la clé à la main).
              2. Entre le code à 6 chiffres qu'elle affiche.
